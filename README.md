# DICE Analyzer: Информационно-энтропийный анализ композитов

## Обзор проекта

**DICE Analyzer** (Dispersion & Information Carbon Evaluator) – это современное веб-приложение, разработанное для автоматизированной оценки однородности распределения технического углерода в композиционных материалах. Приложение использует передовой **информационно-энтропийный метод** для предоставления количественных и визуальных результатов, помогая специалистам быстро принимать решения о качестве и пригодности материалов.

Проект состоит из двух основных частей:
*   **Frontend (Пользовательский интерфейс):** Интерактивное веб-приложение на Next.js, позволяющее пользователю загружать изображения, настраивать параметры анализа и просматривать результаты.
*   **Backend (Серверная часть):** Мощный сервер на FastAPI (Python), который выполняет все сложные вычисления, обработку изображений и генерацию отчетов.

## Основная Методология: Информационно-энтропийный анализ

### Проблема
Однородность распределения технического углерода является критически важным параметром для композиционных материалов, влияющим на их физические, механические и электрические свойства. Неоднородное распределение может привести к дефектам, снижению производительности и сокращению срока службы изделий. Традиционные методы оценки часто субъективны и трудоемки.

### Подход DICE Analyzer
Наше приложение решает эту проблему, применяя **информационно-энтропийный метод**, который включает следующие шаги:

1.  **Микрофотография:** Исходным данным служит сканирующая электронная микрофотография (СЭМ-изображение) композиционного материала.
2.  **Разбиение на ячейки:** Изображение автоматически разбивается на равные квадратные ячейки (размер сетки N x N). Каждая ячейка рассматривается как отдельный участок материала.
3.  **Расчет концентрации:** Для каждой ячейки определяется средняя яркость, которая затем преобразуется в **концентрацию технического углерода (ТУ)** с использованием калибровочных коэффициентов, специфичных для типа материала и кратности увеличения.
4.  **Статистический анализ:** Рассчитываются основные статистические параметры распределения концентраций ТУ по всем ячейкам:
    *   **Математическое ожидание M[X]** (средняя концентрация).
    *   **Стандартное отклонение $\sigma$**.
    *   **Коэффициент асимметрии** и **Коэффициент эксцесса**.
    *   **Информационная энтропия H(P)**.
5.  **Информационно-энтропийный интервал (ИЭИ) $[A_1, A_2]$:**
    Это ключевой параметр, определяющий диапазон концентраций, в котором должна находиться большая часть ячеек однородного материала. Интервал определяется на основе математического ожидания и информационно-энтропийного параметра $\Delta$.

    Формулы для границ интервала:
    $A_1 = M[X] - \Delta \quad (1)$
    $A_2 = M[X] + \Delta \quad (2)$

    Информационно-энтропийный параметр $\Delta$ вычисляется по следующей сложной формуле (2.16 из `Method_algorithm.md`), где $d$ — ширина бина гистограммы, $n$ — общее количество ячеек, $n_i$ — количество ячеек в $i$-м бине:
    $\Delta = \frac{d}{2} \cdot \frac{n}{\sqrt[n]{\prod_{i=1}^{m}(n_{i})^{n_{i}}}}$

    *Примечание:* Для обеспечения численной стабильности и предотвращения ошибок деления на ноль, в реализации были добавлены механизмы обработки крайних случаев (например, если энтропия равна нулю или возникают бесконечные/неопределенные значения).
6.  **Критерий однородности D_IEI:**
    Это основной показатель однородности, который выражается в процентах и показывает долю ячеек, концентрация ТУ в которых попадает в рассчитанный интервал $[A_1, A_2]$.
    $D_{IEI} = \frac{\text{Количество ячеек в интервале}}{\text{Общее количество ячеек}} \times 100*$

    На основе значения D_IEI материал классифицируется по степени однородности согласно следующей таблице:

    | D_IEI, %           | Категория однородности     | Заключение для применения в обогревателе                                                                                                                                                                                              |
    | :----------------- | :------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
    | D_IEI &ge; 95      | ИДЕАЛЬНАЯ / ВЫСОКАЯ        | Образец **ГОДЕН**. Обеспечивает максимально равномерное тепловое поле ($\Delta T < 2^\circ C$). Рекомендован для ответственных применений (обогрев молодняка).                                                                        |
    | 85 &le; D_IEI < 95 | ДОСТАТОЧНАЯ                | Образец **УСЛОВНО ГОДЕН**. Возможны незначительные локальные отклонения температуры. Требует проверки тепловизионным контролем. Пригоден для менее критичных применений (обогрев труб).                                                      |
    | 70 &le; D_IEI < 85 | НИЗКАЯ                     | Образец **НЕ РЕКОМЕНДОВАН**. Высокая вероятность "горячих" и "холодных" пятен, неравномерный износ, риск локального перегрева.                                                                                                         |
    | D_IEI < 70         | НЕДОСТАТОЧНАЯ (БРАК)       | Образец **НЕ ГОДЕН**. Выраженная макронеоднородность, наличие крупных агломератов или непрокрасов.                                                                                                                                     |

### Калибровочные коэффициенты
Концентрация ТУ рассчитывается с использованием параболической зависимости $C = a \cdot B^2 + b \cdot B + c$, где $B$ — средняя яркость ячейки, а $a, b, c$ — калибровочные коэффициенты. Эти коэффициенты специфичны для каждого **материала** и **кратности увеличения**, обеспечивая точность анализа.

## Ключевые возможности приложения

*   **Интуитивно понятный интерфейс:** Простой и современный дизайн, позволяющий легко загружать изображения и настраивать параметры.
*   **Гибкие параметры анализа:** Возможность выбора марки технического углерода, кратности увеличения и размера сетки для анализа.
*   **Детальные результаты:** Приложение предоставляет полный набор статистических данных (M[X], H(P), $\Delta$, $A_1$, $A_2$, D_IEI, асимметрия, эксцесс).
*   **Визуализация сетки:** Интерактивная карта распределения концентрации ТУ, где ячейки, выходящие за пределы информационно-энтропийного интервала, подсвечиваются красным.
*   **Гистограмма распределения:** Графическое представление распределения концентраций с отмеченными границами интервала и математическим ожиданием.
*   **Таблица данных по ячейкам:** Полная детализация концентрации и статуса каждой ячейки изображения.
*   **Экспорт данных:**
    *   **CSV:** Экспорт сырых данных по каждой ячейке в формате CSV.
    *   **PDF-отчет:** Генерация профессионального PDF-отчета, включающего все ключевые результаты, выводы, а также графики гистограммы и визуализации сетки.

## Начало работы (локальная разработка)

Для запуска приложения на вашем локальном компьютере выполните следующие шаги:

### 1. Предварительные требования

Убедитесь, что у вас установлены:
*   [Node.js](https://nodejs.org/) (рекомендуется LTS-версия) и [npm](https://www.npmjs.com/).
*   [Python 3.8+](https://www.python.org/downloads/).
*   [Git](https://git-scm.com/downloads/).

### 2. Клонирование репозитория

Откройте терминал и выполните:
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd dice-analyzer-development
```

### 3. Настройка Frontend (веб-интерфейс)

В корневой директории проекта (`dice-analyzer-development`):
```bash
npm install
npm run dev
```
Веб-приложение будет доступно по адресу `http://localhost:3000`.

### 4. Настройка Backend (серверная часть)

Перейдите в директорию `api`, которая содержит код FastAPI:
```bash
cd api
```
Создайте и активируйте виртуальное окружение:
```bash
python -m venv .venv
.\.venv\Scripts\activate # Для Windows
# source .venv/bin/activate # Для macOS/Linux
```
Установите необходимые Python-пакеты:
```bash
.\.venv\Scripts\pip install -r requirements.txt
```
**Важно: Файл шрифта для PDF-отчетов**
Для корректного отображения кириллицы в PDF-отчетах необходимо разместить файл шрифта `DejaVuSans.ttf` в директории `api/src/core/`.
Вы можете скачать этот шрифт, например, отсюда: [DejaVu Sans TTF](https://github.com/dejavu-fonts/dejavu-fonts/releases/download/version_2_37/dejavu-fonts-ttf-2.37.zip)
После скачивания распакуйте архив и скопируйте файл `DejaVuSans.ttf` в `api/src/core/`.

Запустите FastAPI-сервер:
```bash
.\.venv\Scripts\uvicorn index:app --reload
```
Сервер будет доступен по адресу `http://127.0.0.1:8000`.

### 5. Запуск приложения

После того как Frontend и Backend серверы запущены, откройте `http://localhost:3000` в вашем браузере. Вы сможете загружать изображения, анализировать их и генерировать отчеты.

## Развертывание на Vercel

Проект готов к развертыванию на [Vercel](https://vercel.com/). Файл `vercel.json` в корне проекта настроен для одновременного развертывания Next.js Frontend и Python FastAPI Backend как Serverless-функций.

Шаги развертывания:
1.  Убедитесь, что все изменения зафиксированы в вашем Git-репозитории.
2.  Отправьте ваш код на GitHub (или аналогичный сервис).
3.  Подключите репозиторий к Vercel через их панель управления. Vercel автоматически обнаружит конфигурацию Next.js и `vercel.json` и развернет приложение.
    *   **В `vercel.json` указана `PYTHON_VERSION: "3.8"`. Убедитесь, что эта версия Python поддерживается вашей конфигурацией Vercel.**
