# DICE Analyzer

Программное обеспечение для количественной оценки однородности распределения технического углерода в композиционных материалах на основе информационно-энтропийного метода.

## Запуск проекта

Для запуска проекта необходимо запустить как бэкенд (FastAPI), так и фронтенд (Next.js).

### 1. Запуск бэкенда (FastAPI)

1.  Откройте терминал (например, Git Bash, PowerShell).
2.  Перейдите в директорию `backend`:
    ```bash
    cd backend
    ```
3.  Активируйте виртуальное окружение:
    *   **Для Windows PowerShell/CMD:**
        ```bash
        .venv\Scripts\activate
        ```
    *   **Для Git Bash (MINGW64) / Linux / macOS:**
        ```bash
        source .venv/Scripts/activate
        ```
4.  Запустите FastAPI приложение:
    ```bash
    uvicorn main:app --reload
    ```
    Бэкенд будет доступен по адресу `http://127.0.0.1:8000`. Держите этот терминал открытым.

### 2. Запуск фронтенда (Next.js)

1.  Откройте **новый, отдельный терминал**.
2.  Перейдите в корневую директорию проекта:
    ```bash
    cd F:\kwork\dice-analyzer-development
    ```
3.  Установите зависимости проекта (если вы этого еще не делали):
    ```bash
    npm install
    ```
4.  Запустите Next.js сервер разработки:
    ```bash
    npm run dev
    ```
    Фронтенд будет доступен по адресу `http://localhost:3000`. Держите этот терминал открытым.

### 3. Доступ к приложению

Откройте ваш веб-браузер и перейдите по адресу: [http://localhost:3000](http://localhost:3000)
