# Инструкция по сборке DICE Analyzer для Windows

Для того чтобы собрать готовое десктопное приложение (.exe), выполните следующие шаги на компьютере с Windows.

## 1. Требования

Убедитесь, что у вас установлены:
- **Node.js** (версия 18 или выше)
- **Python** (версия 3.9 или выше)
- **Git**

## 2. Подготовка

1. Откройте терминал (PowerShell или CMD) в корневой папке проекта.
2. Установите зависимости для основного процесса:
   ```bash
   npm install
   ```
3. Установите зависимости для фронтенда:
   ```bash
   cd client
   npm install
   cd ..
   ```

## 3. Сборка бэкенда (Python)

Мы превратим Python-код в один исполняемый файл `.exe`.

1. Установите необходимые пакеты Python:
   ```bash
   pip install pyinstaller -r server/api/requirements.txt
   ```
2. Запустите сборку:
   ```bash
   pyinstaller --noconfirm --onefile --name dice_backend --paths server/api server/api/index.py
   ```
3. После завершения файл появится в папке `dist/dice_backend.exe`.

## 4. Сборка фронтенда (Next.js)

1. Перейдите в папку клиента и соберите статический сайт:
   ```bash
   cd client
   npm run build
   cd ..
   ```
   *Это создаст папку `client/out` со всеми файлами интерфейса.*

## 5. Сборка финального приложения (Electron)

1. Запустите финальную сборку установщика:
   ```bash
   npm run dist
   ```
2. Готовый установщик (`DICE Analyzer Setup 1.0.0.exe`) будет находиться в папке `dist-electron/`.

## Как работает активация (для разработчика)

Система защиты привязана к **Hardware ID (HWID)** пользователя.
Для генерации ключа активации используется алгоритм:
`SHA256(HWID + "dice-analyzer-secret-salt-2024")`
Вам нужно взять первые 16 символов этого хеша в верхнем регистре — это и будет ключ для клиента.

Вы можете найти код генерации в `electron/licensing.js`.
