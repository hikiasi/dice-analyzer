# Инструкция по сборке DICE Analyzer для Windows

Для того чтобы собрать готовое десктопное приложение (.exe), выполните следующие шаги на компьютере с Windows.

## 1. Требования

Убедитесь, что у вас установлены:
- **Node.js** (версия 18 или выше)
- **Python** (версия 3.9 или выше)
- **Git**

## 2. Подготовка

1. Откройте терминал (PowerShell или CMD) в корневой папке проекта.
2. Установите зависимости для основного процесса:
   ```bash
   npm install
   ```
3. Установите зависимости для фронтенда:
   ```bash
   cd client
   npm install
   cd ..
   ```

## 3. Сборка бэкенда (Python)

Мы превратим Python-код в один исполняемый файл `.exe`.

1. Установите необходимые пакеты Python:
   ```bash
   pip install pyinstaller -r server/api/requirements.txt
   ```
2. Запустите сборку:
   ```bash
   pyinstaller --noconfirm --onefile --name dice_backend --paths server/api server/api/index.py
   ```
3. После завершения файл появится в папке `dist/dice_backend.exe`.

## 4. Сборка фронтенда (Next.js)

1. Перейдите в папку клиента и соберите статический сайт:
   ```bash
   cd client
   npm run build
   cd ..
   ```
   *Это создаст папку `client/out` со всеми файлами интерфейса.*

## 5. Сборка финального приложения (Electron)

**ВАЖНО:** Перед сборкой Electron убедитесь, что в папке `dist/` уже лежит файл `dice_backend.exe`. Если его нет, выполните шаг 3.

1. Запустите финальную сборку установщика:
   ```bash
   npm run dist
   ```
2. Готовый установщик (`DICE Analyzer Setup 1.0.0.exe`) будет находиться в папке `dist-electron/`.

## 6. Решение проблем (Troubleshooting)

### Ошибка "Access is denied" при сборке
Эта ошибка возникает, если файл `dice_backend.exe` занят другой программой или самой Windows.
1. **НЕ открывайте `dice_backend.exe` вручную.** Приложение Electron само запустит его в нужный момент. Файл должен просто находиться в папке `dist/`.
2. Если ошибка возникла, откройте **Диспетчер задач** (Ctrl+Shift+Esc), найдите в списке процессов `dice_backend.exe` и завершите его.
3. Попробуйте удалить папку `dist-electron` вручную перед запуском сборки.

### Ошибка "Failed to fetch" в приложении
Это значит, что фронтенд не может достучаться до бэкенда.
1. Проверьте файл `backend.log` в папке `%APPDATA%/dice-analyzer/`. Там будет написано, почему сервер не смог запуститься.
2. Убедитесь, что порт 8000 не занят другой программой.

## Как работает активация (для разработчика)

1. **Пробный период**: По умолчанию пользователю доступно 30 запусков анализа. Счетчик хранится локально в `license.json` в папке данных приложения.
2. **HWID Активация**: Система защиты привязана к **Hardware ID (HWID)** пользователя.
   Для генерации ключа активации используется алгоритм:
   `SHA256(HWID + "dice-analyzer-secret-salt-2024")`
   Вам нужно взять первые 16 символов этого хеша в верхнем регистре — это и будет ключ для клиента.

Вы можете найти код генерации и логику счетчика в `electron/licensing.js`.
