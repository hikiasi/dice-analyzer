# Проект: DICE Analyzer (Desktop Version)
**Цель:** Разработка научного ПО для оценки однородности распределения технического углерода (ТУ) в композитах на основе информационно-энтропийного анализа СЭМ-изображений.

## 1. Технологический стек
- **Frontend:** Next.js + Tailwind CSS + shadcn/ui + Lucide Icons.
- **Backend (Core):** Python (FastAPI или локальный сервер) + OpenCV + NumPy + SciPy.
- **Desktop Wrapper:** Electron или Tauri (для сборки в .exe).
- **Визуализация:** Recharts (для гистограмм).

## 2. Алгоритм и Математика (Аудит)
Программа должна реализовывать следующие этапы:
1. **Препроцессинг:** Загрузка изображения, перевод в Grayscale.
2. **Сегментация:** Разбиение изображения на сетку $N \times N$ (по умолчанию 15x15 = 225 ячеек, настраиваемо).
3. **Калибровка (C = f(G)):**
   - Для каждой ячейки считается средняя яркость $G_i$.
   - Локальная концентрация $C_i$ вычисляется по калибровочным кривым (полиномы из PDF). 
   - *Важно:* Реализовать выбор марки ТУ (П-234, П-324) и кратности увеличения (5000x, 10000x, 20000x).
4. **Статистический блок:**
   - Математическое ожидание: $M[X] = \frac{1}{n} \sum C_i$.
   - Энтропия Шеннона $H(P)$: расчет по распределению яркостей.
   - Информационно-энтропийный интервал: $\Delta = \frac{10 - H(P)}{H(P)} \cdot M[X]$.
   - Границы: $A1 = M[X] - \Delta$, $A2 = M[X] + \Delta$.
5. **Финальный критерий ($D_{IEI}$):**
   - Процент ячеек, попавших в интервал $[A1, A2]$.

## 3. Функциональные требования к интерфейсу
### Главный экран:
- Область загрузки файла (Drag-and-drop).
- Боковая панель настроек:
  - Выбор марки ТУ (Dropdown).
  - Установка размера сетки (Input).
  - Кнопка "Запустить расчет".
### Панель результатов (Tabs):
- **Вкладка "Анализ":** Вывод $D_{IEI}$ крупным шрифтом, текстовый вердикт (ИДЕАЛЬНАЯ/НИЗКАЯ и т.д.) и пригодность для "обогрева молодняка".
- **Вкладка "Гистограмма":** Распределение концентраций с наложенными линиями границ А1 и А2.
- **Вкладка "Сетка":** Исходное изображение с наложенной сеткой, где ячейки, не попавшие в интервал, подсвечены красным.

## 4. Логика классификации (согласно ТЗ)
- $D_{IEI} \ge 95\%$: ИДЕАЛЬНАЯ/ВЫСОКАЯ (Годен для обогрева молодняка, $\Delta T < 2^\circ C$).
- $85\% \le D_{IEI} < 95\%$: ДОСТАТОЧНАЯ (Условно годен).
- $70\% \le D_{IEI} < 85\%$: НИЗКАЯ (Не годен).
- $D_{IEI} < 70\%$: НЕУДОВЛЕТВОРИТЕЛЬНАЯ (Агломераты).
